# Machine Learning Models

Coursework for an Artificial Intelligence class (CSCI 431) at Stetson University. This repository contains machine learning projects organized by learning type.

## Repository Structure

```
supervised/          # Labeled data, known outcomes
semi-supervised/     # Mix of labeled and unlabeled data
unsupervised/        # No labels, finding hidden patterns
```

## Projects

### Supervised Learning

- **Titanic Survival Prediction** (`supervised/titanic-assignment1/`) - Binary classification model predicting passenger survival on the Titanic using Logistic Regression and Random Forest. Achieved 82% accuracy.
